# Уютный ужин — обновления

Публичный канал обновлений Android-приложения «Уютный ужин». Здесь лежат только `version.json` и APK-релизы. Исходный код и веб-версия находятся в приватных репозиториях.

Приложение при запуске читает `version.json`, сравнивает `versionCode` с установленным и предлагает обновление. APK скачивается по `apkUrl` и проверяется по `sha256`.
